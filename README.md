# 新加功能接口

| 接口 | 方法 |说明 |
|:-----|:-----|-------:|
| /register | POST |注册  |
| /login    | POST |登录  |
| /logout   | POST |登出  |
| /forget   | POST |忘记密码  |
| /favorite   | GET |获取收藏列表  |
| /album_tracking   | POST |获取连载追踪列表  |
| /notifications   | GET |获取通知列表  |
| /album_sertracking   | POST |切换追踪状态  |
| /album_sertracking   | GET |获取追踪状态  |
| /favorite   | POST |切换收藏  |

# 新加功能与页面

###### Chapter页面

- 添加章节列表
- 添加切换收藏
- 切换追踪状态

###### User页面

- 添加注册
- 添加登录
- 添加登出
- 添加忘记密码
- 添加获取收藏列表
- 添加获取连载追踪列表
- 添加获取通知列表
